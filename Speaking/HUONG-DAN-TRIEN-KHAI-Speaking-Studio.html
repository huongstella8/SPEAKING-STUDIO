Cách ba trang nhận nội dung

Mỗi trang không mang sẵn nội dung nào. Nó nhìn vào đuôi link để biết cần đọc file nào.

LinkTrang đọc file
app.html?m=05data/modules/05.json
skills.html?p=2data/skills/p2.json
practice.html?p=1data/practice/p1.json

Vì vậy thêm module mới là thêm một file JSON, không phải thêm một trang.

Quy tắc vàng Sửa nội dung → tải lên một file trong data/. Sửa ứng dụng → tải lên một file HTML. Hai việc này không bao giờ phải làm cùng lúc, và không việc nào cần đụng tới Apps Script.

1Đưa cả thư mục lên GitHub

Làm một lần, khoảng năm phút. Sau bước này cô không phải lặp lại nữa.

  1. Giải nén speaking-site.zip. Bên trong là thư mục site chứa 22 file.
  2. Đổi tên thư mục site thành speaking.
  3. Mở github.com, vào repository ARIES.
  4. Bấm Add file → Upload files.
  5. Kéo nguyên cả thư mục speaking vào vùng thả file. GitHub giữ nguyên cấu trúc thư mục con, không cần kéo từng file.
  6. Bấm Commit changes, đợi một đến hai phút để GitHub Pages cập nhật.
Kiểm tra nhanh Mở https://huongstella8.github.io/ARIES/speaking/. Phải thấy trang chủ màu vàng hổ phách với ba nhóm link: Skills, Practice, Topic modules. Nếu thấy danh sách file thay vì trang chủ, nghĩa là index.html chưa tải lên — kéo lại file đó.

2Kiểm tra trước khi gửi học sinh

Hai phút. Mở bằng cửa sổ ẩn danh (Cmd + Shift + N) để thấy đúng như học sinh thấy.

  • Từ trang chủ, bấm vào Part 2 — Long Turn. Trang phải hiện đủ bảy tab, không trống.
  • Quay lại, bấm vào 01 Technology & Media. Tab Vocabulary phải có bảng từ vựng, không phải dòng "in preparation".
  • Vào tab Studio, chọn Part 1, bấm Start. Phải nghe thấy giọng đọc câu hỏi, và màn hình chỉ hiện "Question 1 of 4 — listening only".
  • Chuyển sang Part 2. Cue card phải hiện đầy đủ ngay, không có nút Start.
  • Bấm Record set. Trình duyệt phải hỏi quyền micro. Cho phép, nói vài câu, bấm Stop & save, rồi nghe lại.
  • Vào tab Report, bấm Download report. File mở được bằng trình duyệt.
Vì sao phải mở qua link GitHub Ba trang này không chạy khi bấm đúp mở từ máy. Trình duyệt chặn trang mở kiểu file:// đọc file dữ liệu của chính nó, và cũng chặn micro. Nếu mở nhầm, trang sẽ hiện một thông báo giải thích rõ chứ không trắng. Đây cũng là lý do bản GitHub tốt hơn bản tải về: GitHub Pages chạy HTTPS nên micro hoạt động trên mọi trình duyệt.

4Nhận kết quả về Google Sheet

Không bắt buộc. Nếu bỏ qua bước này, học sinh vẫn tải được báo cáo và file CSV rồi gửi cho cô theo cách thông thường.

  1. Tạo một Google Sheet mới, đặt tên Speaking — Practice Results.
  2. Vào Extensions → Apps Script, dán đoạn mã trong tài liệu 03 — Lưu kết quả vào Excel / Google Sheet.
  3. Bấm Deploy → New deployment, chọn Web app, Execute as là Me, Who has access là Anyone. Sao chép địa chỉ dạng …/exec.
  4. Mở file config.json trên GitHub, bấm biểu tượng bút chì, dán địa chỉ vào ô submitUrl, bấm Commit changes.
// config.json sau khi điền
{
  "version": "202610091030",
  "submitUrl": "https://script.google.com/macros/s/AKfy…/exec"
}
Điểm quan trọng Sau bước này học sinh không phải dán link nữa. Ô nhập link ở đầu trang tự điền sẵn và khoá lại. Nếu sau này địa chỉ Apps Script thay đổi vì bất kỳ lý do gì, cô sửa đúng một file config.json và mười sáu trang cùng cập nhật — không phải build lại gì cả.

5Mỗi nội dung mới

Hiện có bốn module đã soạn đầy đủ (01, 02, 04, 05), phủ 30 trên 66 cue card của quý. Sáu module còn lại đang ở trạng thái đủ ngân hàng câu hỏi, Studio và phần tự chấm vẫn chạy, chỉ thiếu ba tab dạy nội dung.

  1. Nhắn cho Claude tên module muốn soạn, ví dụ soạn tiếp 09 Experiences.
  2. Nhận về một file, ví dụ 09.json.
  3. Trên GitHub, vào speaking/data/modules/, bấm Add file → Upload files, kéo file vào. File trùng tên sẽ ghi đè.
  4. Bấm Commit changes, đợi một phút, mở app.html?m=09 kiểm tra tab Vocabulary đã có nội dung.

Link không đổi. Học sinh đang mở trang chỉ cần tải lại. Trang chủ tự chuyển nhãn module đó từ trống sang full.

Sửa một lỗi nhỏ cũng vậy Sai một từ trong bảng từ vựng module 04 thì cũng chỉ tải lại 04.json — khoảng 25 KB, không phải một file HTML 75 KB. Đây chính là chỗ kiến trúc mới tiết kiệm công nhất.

6Khi cần sửa ứng dụng

Ví dụ đổi cách hiển thị, thêm nút, đổi quy tắc tính giờ. Trước đây việc này phải build lại và tải lên cả mười sáu file; bây giờ là một.

Sửa thứ gìTải lên file nào
Giao diện hoặc chức năng của 10 module chủ đềapp.html
Ba file kỹ năng Part 1/2/3skills.html
Ba file luyện tập Part 1/2/3practice.html
Danh sách trên trang chủindex.html và manifest.json

Sau khi tải lên, bảo học sinh bấm Cmd + Shift + R một lần. Nếu cô sửa version trong config.json thì không cần bước đó, vì trình duyệt tự nhận ra bản mới.

CVề mười sáu file HTML bản cũ

Các file 01-technology-and-media.html, SKILLS-part-1.html, PRACTICE-part-1.html… vẫn chạy được bình thường và vẫn tự chứa đầy đủ nội dung. Cô có thể giữ lại để gửi cho học sinh không tiện vào mạng.

Nhưng không nên dùng song song cả hai bản lâu dài: sửa nội dung ở bản tách sẽ không tự lan sang bản tự chứa, và ngược lại. Nếu đã chuyển sang bản GitHub thì nên coi mười sáu file cũ là bản lưu trữ của tháng 10, và từ đó chỉ cập nhật một nơi.
